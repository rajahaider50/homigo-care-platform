# MVP scope note

For the current minimalist MVP, reuse this design system as-is. Do not create UI for deferred roles/features. Prioritize the Patient booking path, shared Doctor/Nurse workflow, Admin verification/booking/SOS views, Health Passport authorization, and SOS alert states.
